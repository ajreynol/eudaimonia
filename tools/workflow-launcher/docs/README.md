# Documentation

Every document in this child project, and what each one is for. The front page,
[`../README.md`](../README.md), is the entry point, and both documents here
assume it has been read.

| document | what it is for |
| --- | --- |
| [`analogy.md`](analogy.md) | The Eudaimonia build system and this one, stage by stage: what transfers, where it breaks, and why the boundary at repository creation is placed where it is. Maintained as the thing this project is for. |
| [`ai-workflows.md`](ai-workflows.md) | The findings register: what this ecosystem is doing that looks novel and might generalise, and what is wrong with it, on one list. Each entry carries its evidence and what would falsify it. |

Two documents is the whole of it, and that is deliberate. The ecosystem's own
account of this failure is blunt about it: a stretch of work that produced
thousands of lines of governance documentation changed nothing about what any
tool found, and writing one more page is the comfortable alternative to doing
the work. A third document here has to displace a question in
[`../interview.md`](../interview.md) or an hour of somebody's reading.
