# Answers

One filled-in interview per launch, written here by `bin/launch new`.

**Not kept in git**, and the reason is worth stating because the analogous
directory downstairs is ignored for a different reason. Generated checkers are
ignored because they are *reproducible* — everything in one is a function of the
settings and the templates, so keeping the output would be keeping a second copy
of the input. Nothing here is reproducible. An answered interview is ignored
because it is **somebody's plan for their own repository**: it belongs in that
repository, next to what it produced, and not in this tree where nobody will
look at it again.

So if a launch produced something worth keeping the record of, copy the answer
file into the repository it created. That is where the question *what was this
actually asked for* gets asked.

This README is the only file here that is tracked.
