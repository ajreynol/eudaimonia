# Calibration prior — eunoia-ecosystem, 2026-09-01

What somebody who has read these trees would call the major events, written
**before** the detectors were run and before any candidate list was seen. Its
digest is not sealed by machine; the ordering of the work is the only evidence
that it was written first, and it is offered as such.

**The calibrator is contaminated, and the recall number below is therefore
optimistic.** This list was written by the same reader who had spent the day
inside these repositories for other reasons. A clean calibration wants somebody
who knows the subject and has not just read it; that is a person, and this is
not one. Recorded because a calibration whose weakness is unstated is worse than
none.

## What I expect the tree to show

1. **logos comes first and is the only long-running artifact** — months of work
   before anything else in the set exists.
2. **A burst at the end of August 2026** in which four repositories appear
   within days of each other.
3. **A governance cluster inside that burst** — a repository policy, a vision, an
   inventory of roles, a reporting policy — written in one tree and adopted by
   the others.
4. **CI appearing early in each new tree**, and one of those jobs running another
   repository's checker against itself.
5. **Child projects being started** inside two of the trees.
6. **Quiet stretches in logos** and none anywhere else, because nothing else has
   existed long enough to be quiet.

## What I expect the detectors to miss

- **Every decision.** Why eudaimonia exists, why koine was approved, why the
  fuzzer was folded back into its parent. These are in prose and in
  correspondence; the tree shows only that files moved.
- **Anything in ethos**, which is excluded from the corpus and holds the compiler
  work that several of these trees are reacting to.
- **The distinction between a repository being created and a project starting.**
  A repository whose first commit imports a finished document did not begin then.

## The number that matters

How many of items 1–6 appear among the candidates. Items in *What I expect the
detectors to miss* are not scored: they are a prediction about the tool's
ceiling, not about this run.
