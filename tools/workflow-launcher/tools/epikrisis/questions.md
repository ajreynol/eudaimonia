# The questions

Pre-registered. Written **before** any corpus was pinned, any detector was run,
or any evidence was looked at — the run manifest records this file's digest, so
a question added later is visible as one.

They are deliberately answerable-in-the-negative. A question only a good answer
fits is not a question.

## For any subject

**Q1. What were the major events?** In order, each resting on evidence a reader
can check.

**Q2. Does the tree show events no document mentions?** The *derived, not
declared* class. Expected to be the most informative and the hardest to be sure
about.

**Q3. Does the declared record claim events the tree does not show?** The
*declared, not derived* class — including claims that are true of work done
somewhere the corpus cannot see, which is not the same thing as a false claim and
must not be reported as one.

**Q4. What has the evolution done well?** Not *what is good about the artifact* —
what about the way it changed over time worked.

**Q5. What has it done badly?** Same tense, same standard of evidence. A run
that cannot answer this has failed, and says so in place of the section.

**Q6. What can this tool not see about this subject, and does that make Q1–Q5
unsafe?** Required in every run, answered last, and permitted to invalidate
everything above it.

## For this subject in particular

**Q7. Is this one process or several?** The ecosystem contains trees of very
different ages. Whether its history is one story or a substantial artifact plus a
recent burst of something else is the first thing a timeline should settle, and
the answer changes what every other question means.

**Q8. Does the density of the declared record correspond to anything in the
trees?** This ecosystem writes down far more about itself than most projects do.
Either that record tracks what happened, in which case the practice is worth
something, or it does not, in which case the practice is worth knowing about for
a different reason.

## What is not asked

Nothing about people, about who did what, or about rates of work — the pipeline
cannot express it and the questions do not ask for it.

Nothing about what the subject should do next.

Nothing comparative. *Better or worse than another project* needs a second
subject run the same way, and one run cannot support it.
