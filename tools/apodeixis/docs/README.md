# Documentation

Every document in this child project, and what each one is for. The charter,
[`../README.md`](../README.md), is the entry point and everything here assumes
it has been read — in particular that the load is Alethe and the subject is
eudaimonia, and that nothing here is offered to the Alethe ecosystem.

| document | what it is for |
| --- | --- |
| [`hypotheses.md`](hypotheses.md) | The seven places the framework and the target are expected to meet badly, written before any run, with the grading a break is assigned. |
| [`method.md`](method.md) | How a run is done, the three rules that keep it from measuring the wrong thing, and what a green run does and does not mean. Goal 3. |

And two directories that are not documentation and are where the work is:

| | |
| --- | --- |
| [`../signature/`](../signature/README.md) | the Eunoia rendering of the target, fragment by fragment. Goal 2 |
| [`../findings/`](../findings/README.md) | the ledger of breaks, one file per entry. Goal 1 |

`work/` is where the generator writes and is untracked: everything in it is
reproducible from a rendering, a parent commit and a command line, all three of
which the ledger records.
